# meetmebythe.com

an experimental interactive poetry site that draws from a bank of poem fragments. each page allows the user to interact with a recombinant poem and experience many combinations and iterations of the poem's fragments. the site explores the visible and hidden, the limits of communication, and meaning-making in proximity.

currently the site has two pages, but that will likely expand with new experiments ;)

you can interact with the site at meetmebythe.com
